# Lead Conversion Predictor

## 📌 Overview
Built a Machine Learning model to predict lead conversion and assign a **Lead Score (0–100)**, helping prioritize high-value prospects.


## Problem
Only ~30% of leads convert.
Goal: Identify high-potential leads and improve targeting efficiency.


## ⚙️ Approach
* Cleaned and preprocessed CRM-style data
* Handled missing values and encoded categorical features
* Trained a **Logistic Regression model**
* Evaluated using **ROC-AUC, Precision, Recall**

## 🔢 Lead Scoring
* Model outputs conversion probability
* Converted to score:

**Lead Score = Probability × 100**
* Higher score → higher chance of conversion
